# MiWiFi panel frontend

## Aviso

Desde la versión **v3.7.0**, el panel frontend de MiWiFi está integrado directamente en la integración de Home Assistant:

https://github.com/JuanManuelRomeroGarcia/hass-miwifi

Las nuevas instalaciones deben instalar `hass-miwifi` mediante HACS. No es necesario instalar este repositorio por separado ni añadir recursos manualmente.

Este repositorio se conserva como referencia histórica para instalaciones antiguas.
